# Гобелен пути

Трекер-путешествие для iPhone: земли, привалы, Странствующая и Колода Пути. Не надсмотрщик, а способ узнавать себя.

Открой в Safari → «Поделиться» → «На экран Домой». Все записи хранятся только на твоём телефоне.
