# Гобелен пути

Мягкий планер жизни в виде путешествия: земли-сферы жизни, цели, привычки-заклинания, сокровищница, вечерний привал, Странствующая и Колода Пути. Без серий, которые сгорают, и без упрёков за пропуски.

Открой в Safari → «Поделиться» → «На экран Домой». Все записи хранятся только на твоём телефоне.
